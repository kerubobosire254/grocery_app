# Stocked

**Your monthly shopping list, sorted.**

Live app: https://kerubobosire254.github.io/grocery_app/

Stocked is a progressive web app I built to solve my own problem: I forget what I need to buy every month.

---

## Why I built it

I forget things. Not big things. The small monthly ones, like cooking oil, toothpaste, detergent.

You only find out when you're home, the bags are unpacked, and the one thing you needed is not in any of them. Some months that means another trip. Some months it means going without.

I knew a list would fix it. The list was the problem.

On paper, I wrote the same items out again every month, and the paper got lost. On my phone, I typed it all out on a tiny keyboard, one item at a time, and gave up halfway. So the list never really got made, and I kept forgetting.

I was tired of doing the same boring job every month, so I built Stocked. My usual items are saved once. Each month I tick what I need and the list is done in seconds.

I built it because I was the person with the problem. I'm the user, the tester and the developer.

---

## What it does

- **Monthly view.** Move between months and keep a separate list for each one.
- **My usual items.** Save the things you buy all the time, so you never type them twice.
- **Add selected to this month.** Tap the items you need and drop them into the current list in one go.
- **Add something new.** Need a one off item? Add it, and choose whether to save it as one of your usual items.
- **Tick as you shop.** Mark items as bought and watch the list shrink.
- **Estimated total.** See roughly what the month's shopping will cost, plus what's bought and what's remaining.
- **Clear ticked items.** Tidy up the list when you're done.
- **Print list.** Prefer paper in the shop? Print it.

## Install it on your phone

Stocked is a PWA, so you can add it to your home screen and open it like a normal app.

**Android (Chrome):** open the link, tap the menu, then **Add to Home screen**.

**iPhone (Safari):** open the link, tap **Share**, then **Add to Home Screen**.

---

## Run it locally

```bash
git clone https://github.com/kerubobosire254/grocery_app.git
cd grocery_app
```

Then open `index.html` in your browser, or serve the folder with any local server.
